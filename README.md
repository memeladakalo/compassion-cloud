# Compassion Cloud

Compassion Cloud is a responsive multi-page disaster relief management website built with pure HTML5, CSS3 and vanilla JavaScript.

## Pages
- index.html — Homepage
- about.html — About the platform
- disaster-response.html — Active and past response information
- relief-requests.html — Relief request form and browser-based demo tracker
- resources.html — Resource availability
- get-involved.html — Volunteer registration
- updates.html — Relief updates
- contact.html — Contact form and organisation details

## Technology
- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage for demonstration relief requests

No Bootstrap, Tailwind, React, or other frameworks are used.

## Run locally
Open `index.html` directly in a browser, or open the project folder in Visual Studio Code.

## Netlify deployment
1. Sign in to Netlify.
2. Choose Add new project / Deploy manually.
3. Upload the `compassion-cloud` project folder or its ZIP contents.
4. Ensure `index.html` is at the project root.
5. No build command is required.

## Notes
This is a front-end demonstration. Forms use client-side validation and browser LocalStorage where appropriate. They do not send real requests to a production backend.
